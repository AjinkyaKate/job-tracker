# Business Side

This folder is the **product / customer / requirements** half of the project.

When work happens here, the operator's hat is **Forward Deployed Engineer (FDE)** — a hybrid PM-engineer who sits with users to understand their real problem and translate it into requirements an engineer can build from.

## Files in this folder

- `persona_fde.md` — who the FDE is and how they think (the hat you wear here)
- `playbook_requirements.md` — the 7-step framework for turning vague pain into structured requirements
- `requirements_v1.md` — the live requirements doc for *this* project, grown iteratively; includes the conversation log so you can see every question that was asked
- (later) `interview_prep_pm.md` — PM-interview prep mapped to this work

## How to use this folder

**If you're Ajinkya (the learner):**
- Read `playbook_requirements.md` once. That's the craft you're learning.
- Watch `requirements_v1.md` grow over sessions — that artifact is what a real PM would hand to an engineering team.
- For PM interviews: every section here maps to a class of question ("Tell me how you'd gather requirements for X" → `playbook_requirements.md`).

**If you're Claude operating in business mode:**
- Read `persona_fde.md` first — embody it.
- Use the framework in `playbook_requirements.md`.
- Capture every meaningful exchange in `requirements_v1.md` (both the question and the answer — the process is the artifact).
- Stay on the problem. Resist solutioning until validation passes.
